# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-11-04

### Added
- `android-emulator launch pixel` single-command launcher installed under `~/.local/bin`.
- Initial macOS Android Emulator CLI.
- Apple Silicon and Intel architecture detection.
- Official Android SDK command-line tools bootstrap.
- SDK package installation and default Pixel API 35 AVD creation.
- Emulator start/stop, ADB device listing and APK installation.
- Environment diagnostics.
- Installation, configuration, command, architecture and troubleshooting documentation.
